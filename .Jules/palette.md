## 2026-10-03 - Backend/Evaluation Harness Repository Context
**Learning:** The Atento repository is a Python backend service and evaluation harness with no frontend UI components (HTML, CSS, JSX/TSX, Vue, Svelte, etc.). UX/UI micro-enhancements do not apply here.
**Action:** When working on this codebase in a UX role, inspect the repository architecture first. If no user interface exists, do not attempt to force UI or frontend changes.
